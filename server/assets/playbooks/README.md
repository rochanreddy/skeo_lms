# Playbooks

The PDFs emailed to a buyer of **Claude Playbooks** (or **Everything AI**) once
Cashfree confirms the payment. Drop the files here and list each one — title and file — in the
order the email should list them, in `playbooks.json` here.

Keep the set comfortably under ~10 MB in total: it goes out as attachments on
one email, and inbox providers start refusing mail well before that gets large.
